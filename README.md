# JSONがわかると、AIが動き出す

非エンジニア向けのJSON入門教材です。AIツールの設定ファイルを **読めて・直せて・書ける** ようになることを目標にしています。

### ▶ [https://hugesesame.github.io/json-guide/](https://hugesesame.github.io/json-guide/)

---

## この教材について

ジェイソンは、人の名前ではありません。AIエージェントを使いはじめると必ず出会う、あの `{ }` だらけの文字列のことです。

MCPの接続設定、AIツールの設定ファイル、AIへの出力形式の指定 — 非エンジニアがJSONに出会う場面は、いまや日常的になりました。しかし既存の解説はプログラマー向けのものがほとんどで、「文法は説明されたが、目の前のエラーが直せない」という状態に置き去りにされがちです。

この教材は、**文法の網羅より、実際に詰まる場所を先回りして潰すこと**を優先しました。JSONを「記入済みの申込用紙」に喩えるところから始め、`読める → 直せる → 書ける` の順に登れるよう構成しています。

想定読者は、プログラミング経験のないAI初心者です。予備知識は要りません。

## 特徴

**JSONチェッカーを内蔵**（第9章）

ブラウザ標準のエラーをそのまま出すのではなく、非エンジニア向けに翻訳します。パーサーを呼ぶ前に自前で走査し、日本語環境で多い誤り — 全角記号・シングルクォート・コメント・末尾カンマ — を、原因と該当行を添えて名指しします。

たとえば末尾カンマの場合、標準パーサーが「4行目」と報告するところを、**実際の原因である3行目18文字目**を指します。文字列の内外を追跡しているため、`{"memo":"りんご、みかん：ぶどう（3つ）"}` のように日本語の全角記号を含む正しいJSONは誤検知しません。

入力内容はページ内で処理され、外部に送信されません。

**1枚完結・依存ゼロ**

`index.html` 1ファイルで完結します。外部CDN、フォント、ライブラリを一切読み込みません。シンタックスハイライタも自前実装です。ダウンロードしてローカルに置くだけでも動作します。

**スマートフォン優先**

スマホでの利用を軸に設計し、ラップトップにも対応するレスポンシブ構成です。タップ領域は44px以上を確保しています。もくじの自動生成、スクロール進捗バー、現在地のハイライトを備えています。
